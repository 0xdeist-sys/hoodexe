STONEFOLK SITE V1

Upload index.html, favicon.png, assets/ and CNAME to the root of the GitHub Pages repository.

Claim is intentionally disabled until contracts are deployed.

After deployment edit the CONFIG values near the bottom of index.html:
STONEFOLK_NFT
REWARD_VAULT
REWARD_ENGINE
OPENSEA_URL

Once REWARD_VAULT is set, its ETH balance is read live from Robinhood Chain every 30 seconds.
